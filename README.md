# Claude Code 기반 전기·전자 엔지니어링 업무 자동화 프로젝트

본 프로젝트는 **앤트로픽(Anthropic)의 자율형 터미널 기반 AI 코딩 에이전트인 Claude Code**를 활용하여 전기·전자 엔지니어링 실무에서 발생하는 반복적이고 복잡한 데이터 처리, 펌웨어 검증, BOM 분석 등의 업무를 자동화하는 GitHub 과제 프로젝트 저장소입니다.

## 🚀 프로젝트 개요
전기·전자 엔지니어링 부서는 부품 데이터시트 검증, 회로 netlist 분석, 하드웨어 제어용 펌웨어 초기화 코드 작성 등 많은 양의 텍스트 기반 사양서와 코드를 다룹니다. 본 프로젝트는 Claude Code의 강력한 CLI 접근 권한과 맥락 이해 능력을 활용해 이러한 업무를 자동화하는 파이프라인과 프롬프트 엔지니어링 템플릿을 제공합니다.

## 📁 디렉토리 구조
```text
.
├── .claude/
│   ├── skills/              # Claude Code가 사용할 커스텀 셸 스크립트/파이썬 툴
│   │   └── validate_bom.py  # BOM 데이터시트 비교 및 EOL 검증 스킬
│   └── agents/              # 멀티 에이전트 팀 구성 설정 (분석, 개발, QA)
├── src/
│   ├── firmware/            # MCU 초기화 및 드라이버 소스 코드 자동 생성 영역
│   └── scripts/             # EDA(KiCad, Altium) netlist 및 시뮬레이션 CSV 분석 파이썬 스크립트
├── templates/
│   └── data_sheets/         # 가상의 부품 데이터시트 레지스터 맵 샘플 (Markdown/JSON)
├── CLAUDE.md                # Claude Code 지시용 핵심 컨텍스트 가이드 파일
└── README.md                # 본 프로젝트 설명서
```

## 🛠️ 주요 기능 및 실습 과제
1. **펌웨어 드라이버 자동 생성**: `templates/data_sheets/`의 레지스터 맵을 기반으로 MCU용 C 언어 레지스터 제어 코드를 Claude Code가 작성 및 빌드 검증하도록 유도합니다.
2. **BOM(자재명세서) EOL 및 대체품 스크래핑**: 부품 리스트를 분석하여 단종 항목을 가려내고 파라메트릭 사양 비교 보고서를 자동 빌드합니다.
3. **시뮬레이션 데이터 시각화 자동화**: PSpice나 LTspice에서 추출된 결과 CSV 데이터를 파싱하여 자동으로 주파수 및 파형 분석 보고서를 생성하는 코드를 AI와 협업하여 완성합니다.

## ⚙️ 시작하기 (Claude Code 연동)
1. **Claude Code CLI 설치**: 앤트로픽의 안내에 따라 터미널에 `claude` CLI를 설치 및 로그인합니다.
2. **컨텍스트 로드**: 본 저장소 루트에서 `claude`를 실행하면 시스템이 자동으로 `CLAUDE.md` 지침을 인식합니다.
3. **과제 수행**: 아래 가이드라인을 참고하여 `/init`, `/compact` 명령어와 함께 에이전트에 엔지니어링 미션을 지시하세요.
